## Trees
### A data structure that combines the advanatges of normal arrays and linked lists, that being able to apply binary search for higher speed yet can growth or shrink memory usage by data amount. A binary search tree uses a 2D family tree like structure, top being the middle sorted value, that cut one large list to two smaller, spread out to two other values, each being middle of their new smaller list, as each value cut their new list to even smaller lists, each of them spread out to two more values being the middle of the even smaller lists and so on. They follow the pattern for binary search, as value at left must be smaller than it parents, and opposite for the value at right. The searching process is recursive as to either go right or left until found value, and since it follows the nature of binary search, its searching time is therefore O(logn), faster than linked lists because each action halfs the amount of data needed to be searched. Because of how each leaf in the tree spread to two others, then it means each nodes contain three information, one as its value and two as pointers to other nodes. Though this leads to the downside of even more memories are needed as each node stores three value instead of two like linked lists or one like normal array.
### To implement the units used for binary search tree, we can reuse the same code for nodes for linked lists, typedef struct node, also one field for main value, and instead of one pointer we declare two field for pointers, one called left and one called right. 
### To apply binary search on the tree we can declare a recursive function that takes in a pointer parameter and a target value parameter, the pointer should be as the root of the tree, then if tree is NULL then return false, because it indicates that the tree is either empty or target value doesn't exist in there, else then we pass on the tree's left or right field pointer to itself and the same target value and return that result based on whether the target value is less than or greater than the tree value, otherwise if equal then return true. So this we successfully recall the same function inside itself acting as a step by step sequence of moving down a leaf a time. The reason why we return false on NULL is because the bottom leaves have no pointers toward other value therefore we put NULL in there and this always indicate the end of the tree and so we know we couldn't find the target value.
### The logic to build a tree in the most simpliest way is to get user input then to compare to last value(s), if less than it then place on left field otherwise right field. However sometimes a tree may devolve from O(logn) to O(n) because of user typing in ascending values, because of the structure of left and right by last value, ascending values will result in the tree becoming a one sided linked tree, which is simply a linked lists and so have all the disadvantage of low speed back, this therefore will require advanced algothrithm to automatically readjust the root of the tree dynamically to avoid the devolve.
